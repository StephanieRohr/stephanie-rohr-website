# Design System

Tailwind CSS v4 plus custom theme tokens/utilities in `src/styles/global.css`.

- **Palette/tokens**: white/black/gray palette, muted text, line color, accent colors, heading font utility, site container width, nav spacing.
- **Fonts**: Raleway via Astro fonts as `--font-heading`; body text uses Helvetica Neue/Arial via `--font-sans`.
- **Layout**: max site width is `--container-site` (`1100px`). Reusable utilities include `section-wrapper`, `page-title`, and gradient/divider helpers.
